# UserManagementAPI with Copilot

This project is a simple User Management API built with ASP.NET Core and enhanced using GitHub Copilot.  
It demonstrates CRUD operations, validation, error handling, and middleware implementation.

## Features
- **CRUD Endpoints**: GET, POST, PUT, DELETE for managing users.
- **Validation**: Ensures only valid user data is processed.
- **Error Handling**: Returns clear error responses for invalid requests.
- **Middleware**:
  - Logging middleware for request/response tracking.
  - Authentication middleware for token validation.
  - Error handling middleware for consistent error responses.
